本版包含第一章「荒嗥」五关及草原无尽原型。闯关从「始行」选择难度与镇锋，完成晴草坡后可选主动技，第五关迎战荒嗥戾牙。

- [手机浏览器试玩](https://geqian513.github.io/ashen-firemament-demo/?v=demo-1) · 建议横屏，左下摇杆移动。
- [下载 Windows 试玩包](https://github.com/geqian513/ashen-firemament-demo/releases/download/demo-1/AshenFiremament-Windows-Demo-1.zip) · 适用于 64 位 Windows，解压后运行 AshenFiremament.exe，使用 WASD 移动。
- [下载 Android APK](https://github.com/geqian513/ashen-firemament-demo/releases/download/demo-1/AshenFiremament-Android-Demo-1.apk) · 适用于 Android 7.0 及以上。
